# Лабораторная работа № 5 — внутренние и анонимные классы

Оригинал задания — [Лаб5.docx](assignment/Лаб5.docx). Документ содержит
17 вариантов. В существующей лабораторной выбран вариант 1.

## Требования варианта 1

1. Создать класс `Notepad` с внутренним классом или классами. Объекты
   внутреннего класса должны позволять хранить несколько записей на одну дату.
2. Продемонстрировать использование анонимного класса в работающем коде.

Условие оставляет выбор алгоритмов, формата хранения, интерфейса и средств
сборки автору.

## Доработка по запросу

- Хранить заметки в файле. После перезапуска должны восстанавливаться обычные
  заметки и напоминания со всеми полями.
- Исправить тесты и проверять работу на временных файлах.
- Описать сборку и запуск в README.

## Критерии проверки

- Две записи на одну дату находятся на одной странице `Notepad.DatePage`.
  Запись на соседнюю дату выдаётся отдельно.
- Анонимный компаратор используется при сортировке общего списка. Сначала
  сравниваются даты, при совпадении даты — заголовки без учёта регистра.
- Повторное открытие файла возвращает те же записи, включая время и признак
  активности напоминания. Очистка также сохраняется.
- Повреждённый файл вызывает ошибку чтения. Попытка добавить заметку в такой
  файл сохраняет его исходное содержимое.
