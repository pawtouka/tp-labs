# Лабораторная 9 — задание 1

Оригинал: assignment/Лаб9.docx.

## Требования
- Исходные тексты брать из текстовых файлов, результат записывать в текстовый файл.
- Создать программу обработки текста учебника по программированию с классами Символ, Слово, Предложение, Абзац, Лексема, Знак препинания и др.
- Предварительно разобрать текст на составные части.
- При формировании текста заменять табуляции и последовательности пробелов одним пробелом.
- Задание 1: найти наибольшее количество предложений текста, в которых есть одинаковые слова.

## Принятая трактовка и критерии
Найти максимальное число различных предложений, содержащих одно общее слово.
Вывести максимум, все слова с этим максимумом и соответствующие предложения.
Повтор слова в одном предложении считается один раз. Регистр не учитывается,
е и ё различаются. При отсутствии повторов максимум равен 1, для пустого текста — 0.
Слово — последовательность Unicode-букв; цифры и другие символы сохраняются
как отдельные лексемы. Конец предложения — последовательность .!? и закрывающих
кавычек/скобок; остаток без конечного знака также считается предложением.
Абзацы разделены переводами строк; сокращения и точки в коде специальным образом
не распознаются. Это ограничения выбранного разбора, не дополнительные требования.
Проверки: модель разбора, регистр, повторы внутри предложения, несколько лидеров,
пустой текст, нормализация пробелов, файлы UTF-8 и ошибки аргументов.
