# Лабораторная 8

Выбраны А1, А13, C1. Полное исходное условие: assignment/Лаб8.docx.

Общие требования: решить каждую задачу двумя способами: методами String и средствами Stream. Обязательно использовать регулярные выражения.

- А1: в каждом слове текста заменить k-ю букву заданным символом. Если k больше длины слова, слово не изменять.
- А13: напечатать без повторения слова текста, у которых первая и последняя буквы совпадают.
- C1: проверить сильный пароль: длина не менее 10 символов, хотя бы одна цифра, одна прописная и одна строчная буква. Разрешены только латинские буквы, цифры и подчёркивание.

Проверка: обе реализации дают одинаковые результаты; проверены границы k, короткие слова, повторы слов, разделители, Unicode и все ограничения пароля.

Принятые правила (условие их не уточняет): слово — последовательность Unicode-букв; k начинается с 1; сравнение букв и устранение повторов учитывают регистр; порядок слов сохраняется; однобуквенные слова подходят А13. Буквы считаются кодовыми точками Unicode. k <= 0 и некорректный код символа отклоняются.
