# Лабораторная работа № 10

Оригинал задания — [Лаб10.docx](assignment/Лаб10.docx).

## Требования

- Прочитать из символьного файла сведения о N числах с плавающей запятой. Для каждого числа отдельно задана локаль.
- Проверить корректность каждой записи и преобразовать число с учётом его локали.
- Вычислить сумму и среднее арифметическое прочитанных чисел.
- Создать собственный класс исключения. Обработать нехватку памяти, отсутствие файла, отсутствие и некорректность записи, выход числа за допустимый диапазон и другие ошибки ввода.

Задание оставляет формат файла, представление чисел и способы вычисления на выбор автора.

## Формат и вычисления в этой реализации

- Файл в UTF-8. Первая строка содержит положительное целое N, затем ровно N строк вида `локаль<TAB>число`. Например, `de-DE<TAB>1.234,50`.
- Поддерживаются локали с доступными в JDK настройками чисел. Используются языковые теги BCP 47, локальные цифры, десятичный разделитель, знак минуса и необязательная группировка по правилам формата JDK. Знак плюс допустим в виде `+`. Допустима экспонента `e` или `E` с цифрами локали и необязательным знаком ASCII.
- Проверяются вся строка числа и группировка целой части. Допускаются дроби без целой части и целые числа без десятичного разделителя. NaN и бесконечности отклоняются.
- Входное число ограничено сверху по модулю точным значением `Double.MAX_VALUE`. Ненулевое значение, округляющееся к нулю в `double`, считается выходящим за диапазон. Сумма вычисляется точно в десятичной арифметике; среднее округляется по DECIMAL128.
- Ошибка завершает обработку с диагностикой. Сумма и среднее выводятся после проверки всего файла.

## Критерии проверки

- Смешанные локали в одном файле дают ожидаемые сумму и среднее. Разделители, группировка, знаки и цифры читаются по локали записи.
- Отсутствие файла, неверное N, пропуск строки, лишняя строка, неверная локаль, лишние символы, некорректная группировка и неверный диапазон диагностируются.
- При реальной нехватке памяти точка входа делает попытку вывести краткое сообщение и завершиться с ошибкой.
