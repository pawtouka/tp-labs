Решить поставленную задачу двумя способами:
1. При помощи функционального интерфейса, написанного вами.
2. При помощи уже существующего в java функционального интерфейса.
Задание № 1
С помощью каррирования реализовать функцию сложения двух чисел, функцию проверки строки на регулярное выражение, функцию разбиения строки по регулярному выражению.
Задание № 13
Создать массив целых чисел. Используя лямбда-выражение, отсортировать массив по убыванию.
Задание № 25
Определить, является ли строка панграммой (использует каждую букву алфавита хотя бы один раз).

Важно: каждое из трёх заданий необходимо реализовать на Java двумя способами согласно общему условию лабораторной работы.
