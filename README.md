# Лабораторная 11 — планировщик учебных задач

Приложение Swing хранит задания по чтению и практике. В главном окне можно
добавить, отредактировать, завершить, возобновить или удалить задачу. Диалог
«Сводка» показывает количество задач, число завершённых и оценку оставшегося
времени. Одна страница оценивается в 3 минуты, одно упражнение — в 12 минут.
Список сортируется по сроку или по приоритету с учётом срока.

[Требования](TASK.md). Оригинальное задание находится в `assignment/`.

## Сборка и запуск

Нужны JDK 17 или новее и Maven. Для запуска окна требуется графическая сессия.
Команды выполняются из корня ветки.

```bash
mvn -f lab11/pom.xml test
mvn -f lab11/pom.xml package
cd lab11
java -jar target/study-planner-1.0.jar
```

По умолчанию задачи хранятся в `tasks.csv` в текущем каталоге. Чтобы выбрать
другой файл, передайте его путь после имени JAR. Каталог файла должен существовать,
быть доступен на запись и поддерживать атомарную замену. Рядом создаётся файл
`<имя CSV>.lck`, который защищает от одновременного редактирования в двух
экземплярах приложения. Приложение сохраняет данные после каждой успешной
операции. Журнал UTF-8 записывается в `lab11.log` и консоль.

## Устройство проекта

- `model` содержит неизменяемые задачи двух видов, валидацию данных и сервис
  операций. Интерфейсы `TaskRepository` и `TaskOrder` отделяют хранение и сортировку.
- `storage` читает CSV и атомарно заменяет файл при записи. Сервис обновляет
  состояние после успешного сохранения.
- `view` отображает главное окно, редактор и сводку. `controller` принимает ввод,
  выполняет операции, обновляет представление и обрабатывает ошибки.
- Реализации Strategy в `SortOrder` меняют критерий сортировки. Уровни
  DEBUG, INFO, WARN и ERROR отражают чтение и сортировку, успешные изменения,
  ошибки валидации и ошибки хранения соответственно.
- JUnit 5 проверяет модель и хранилище. Mockito подменяет внешний репозиторий
  в тестах сервиса. Интеграционные тесты используют временный CSV.
