# Лабораторная 10 — числа с учётом локали

[Требования и формат входа](TASK.md). Оригинал находится в каталоге `assignment/`.

Требуются Bash и JDK 17 или новее. При необходимости укажите путь к JDK через
`JAVA_HOME`. Команды выполняются из корня репозитория.

```bash
./lab10/build.sh build
./lab10/build.sh test
./lab10/build.sh run lab10/examples/numbers.txt
```

Укажите свой UTF-8-файл вместо примера. Относительные пути считаются от текущего каталога.
Первая строка содержит число записей. Каждая следующая строка содержит языковой
тег и число, разделённые табуляцией. Пример выводит сумму `1002.5` и среднее
`334.1666666666666666666666666666667`. Код выхода `1` означает ошибку данных,
чтения или нехватку памяти, код `2` — неверные аргументы.

`NumberFile` читает записи по одной, `LocalizedNumber` проверяет локальный синтаксис
числа, `NumbersException` хранит категорию ошибки и номер строки. `Main` выводит
результат или диагностику. Для суммы используется точная арифметика `BigDecimal`,
для среднего — округление до 34 значащих цифр по DECIMAL128. JDK определяет
доступные локали и их разделители.
