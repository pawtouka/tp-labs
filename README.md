# Лабораторная 9 — общий текст в предложениях

Условие, трактовка пункта 1 и ограничения разбора: [TASK.md](TASK.md).
Оригинал DOCX находится в `assignment/`.

Требуется JDK 17+, внешние библиотеки не нужны. При необходимости задайте JAVA_HOME.
Команды из корня этой ветки:

```bash
./lab9/build.sh build
./lab9/build.sh test
./lab9/build.sh run examples/input.txt build/result.txt
cat lab9/build/result.txt
```

Пути ввода и вывода в команде run отсчитываются от `lab9/`, поскольку build.sh
переходит в свой каталог. Можно передать абсолютные пути. Файлы — UTF-8.
Родительский каталог результата должен существовать. Совпадение входного и
выходного файла отклоняется; существующий отдельный выходной файл перезаписывается.

`Text` содержит `Paragraph`, абзац — `Sentence`, предложение — `Lexeme`.
Лексемы представлены `Word`, `Punctuation`, `OtherLexeme`, каждая предоставляет
список `Symbol`. Коллекции модели неизменяемы. `TextParser` разбирает и нормализует
текст, `CommonWords` строит индекс слово → номера предложений, `Main` отвечает
за файловый ввод и вывод. Повторы слова внутри одного предложения не увеличивают
счётчик. Выводятся все слова с максимальным результатом, в порядке String,
и предложения в исходном порядке. При отсутствии слов выводится максимум 0.

Продолжены соглашения прошлых работ: Java 17, пакеты by.*, отдельная модель,
самостоятельный скрипт сборки и тесты без зависимостей. Индекс исключает попарное
сравнение всех предложений. Регулярные выражения не распознают всю грамматику:
сокращения, десятичные числа и код с точками могут разбиваться на предложения.

Тесты проверяют разбор модели, нормализацию, повторения, несколько лидеров,
Unicode, пустой текст, остаток без точки, кавычки, файловый цикл и защиту входа.
