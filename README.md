# Лабораторная работа № 5 — блокнот

PATAPENKA TIMAFEY 2C11GR

Блокнот хранит несколько записей на одну дату, ищет по части заголовка
и сортирует записи по дате и заголовку. [Требования](TASK.md) ·
[Оригинал задания](assignment/Лаб5.docx)

## Сборка и запуск

Нужны JDK 17 или новее и Maven. Выполните из корня ветки:

```bash
mvn -f lab5/pom.xml test
mvn -f lab5/pom.xml package
java -jar lab5/target/notepad-1.0.jar add 2026-10-28 "Покупки" "Купить тетради"
java -jar lab5/target/notepad-1.0.jar remind 2026-10-28 09:00 true "Встреча" "Подготовиться"
java -jar lab5/target/notepad-1.0.jar list 2026-10-28
java -jar lab5/target/notepad-1.0.jar search "ПОКУП"
```

Команда `list` без даты показывает все заметки в порядке сортировки.
Параметр `--file путь` перед командой выбирает другой файл. По умолчанию
используется `notes.txt` в текущем каталоге. Каталог должен существовать
и поддерживать атомарную замену файла. Параметр `true` или `false` задаёт
сохраняемый признак активности напоминания. Приложение показывает это значение
при просмотре. Уведомления по времени не предусмотрены.

## Устройство проекта

- `Notepad.DatePage` — внутренний класс. При чтении блокнот собирает записи
  из файла в страницы по датам. Список одной страницы доступен только для чтения.
- `NotepadService` ищет по заголовку и сортирует общую выдачу анонимным
  классом `Comparator<Note>`.
- `NoteFile` читает записи в формате UTF-8 с разделителями-табуляциями.
  Заголовок и текст кодируются в Base64, чтобы сохранить табуляцию и переносы
  строк внутри заметки. Файл `notes.txt.lck` используется для координации
  записей. Добавление и очистка атомарно заменяют файл данных.
- JUnit 5 проверяет фабрику, группировку по датам, сортировку, поиск,
  повторное открытие файла, очистку и обработку повреждённых данных. Тесты
  используют временные каталоги. Расширение JUnit пишет результат тестов
  через Log4j 2 в консоль и каталог `logs/`.
