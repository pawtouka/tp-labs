# Лабораторная 8

Условие и принятые правила: [TASK.md](TASK.md). Оригинал — в `assignment/`.
Java 17+, без внешних зависимостей. При необходимости задайте `JAVA_HOME`.

```bash
./lab8/build.sh build
./lab8/build.sh test
./lab8/build.sh run a1 'кот, дом!' 2 '*'
./lab8/build.sh run a13 'топот, дед, кот, топот'
./lab8/build.sh run c1 'Abcdefghi1'
```

Каждая команда выводит результаты String и Stream. `Tasks` содержит алгоритмы,
`Main` — консольный интерфейс; общие операции над Unicode вынесены в закрытые
методы. Пакеты `by.*`, JDK 17 и автономный build.sh продолжают подход лабораторных
6–7. Регулярные выражения выделяют слова и проверяют пароль; Stream используется
для преобразования токенов, фильтрации и проверки символов. Для String-решения
используются substring, Matcher и последовательный обход.

Тесты проверяют обе реализации по ожидаемым результатам: границы позиции,
разделители, повторения, Unicode, пустой ввод и каждое ограничение пароля.
Слова определяются по буквам, без морфологического анализа; регистр значим.
